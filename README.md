This is the official GitHub repo for the WolfEnchantments mod. Empower your furry companions with interesting and powerful new enchantments! You can download this mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/wolf-enchantments) or [Modrinth](https://modrinth.com/mod/wolf-enchantments). Please report issues [here](https://github.com/Darkhax-Minecraft/Wolf-Enchantments/issues).

## Maven Dependency
This project is available on the [BlameJared Maven](https://maven.blamejared.com).

If you are using [Gradle](https://gradle.org) you can add the mod as a dependency by adding the following
to your `build.gradle` file.

```groovy
repositories {
    maven {
        url 'https://maven.blamejared.com'
    }
}

dependencies {
     // NeoForge
     implementation group: 'net.darkhax.wolfenchantments', name: 'wolfenchantments-neoforge-26.1.2', version: '26.1.2.0'
     // Fabric
     implementation group: 'net.darkhax.wolfenchantments', name: 'wolfenchantments-fabric-26.1.2', version: '26.1.2.0'
     // Common / MultiLoader / Vanilla / No Loader
     implementation group: 'net.darkhax.wolfenchantments', name: 'wolfenchantments-common-26.1.2', version: '26.1.2.0'
}
```
